只改 import，商業邏輯一行都不用動

LocalBot 提供與 line-bot-sdk 相同的類別與方法名稱：LineBotApi、WebhookHandler、TextSendMessage、TemplateSendMessage、FlexSendMessage……

原本的 LINE Bot

from linebot import LineBotApi, WebhookHandler
from linebot.models import *
from linebot.exceptions import InvalidSignatureError

line_bot_api = LineBotApi(TOKEN)
handler = WebhookHandler(SECRET)

改用 LocalBot

from localbot import LineBotApi, WebhookHandler
from localbot.models import *
from localbot.exceptions import InvalidSignatureError

line_bot_api = LineBotApi(TOKEN, server_url="https://你的網域")
handler = WebhookHandler(SECRET)

五分鐘快速開始

需要 Python 3.10 以上。第一次啟動會自動產生金鑰，不必手動設定。

啟動平台

git clone https://github.com/kochunchung/localbot.git
cd localbot/server
pip install -r requirements.txt
python app.py

啟動你的 Bot

python example_bot.py

安裝 App 並連線

下載 APK 安裝，在設定頁填入伺服器網址與 App Secret（位於 server/.localbot_secrets.json），就能開始聊天。

安全性是預設值

Webhook 使用 HMAC-SHA256 簽名，Bot API 需要 Bearer Token，App 每位使用者都有獨立存取憑證，上傳檔案有類型與大小限制。金鑰、資料庫與媒體檔都不會進版本控制。
